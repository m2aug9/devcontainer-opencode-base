# devcontainer-opencode-base

devcontainer-opencode-baseは、OpenCodeを使用するための基本的な開発環境を提供するDevContainerです。この環境には、AWS CLI、AWS CDK、およびOpenCodeがインストールされており、AWS Bedrockを使用した開発に必要なツールが揃っています。

- [OpenCode実行ガイド](./docs/opencode-guide.md)

## ブランチ

- `main` ブランチは、安定版のコードを保持します。
- `dev` ブランチは、開発中のコードを保持します。
  - `feature/*` ブランチは、新機能の開発に使用されます。
  - `bugfix/*` ブランチは、バグ修正に使用されます。
  - `release/*` ブランチは、リリース準備のためのコードを保持します。
  - `hotfix/*` ブランチは、緊急のバグ修正に使用されます。

## コミットメッセージのルール

- コミットメッセージは、以下の形式で記述してください。
  ```
  <type>: <subject>
  ```
- `<type>` は、コミットの種類を示します。以下のいずれかを使用してください。
  - `feat`: 新機能の追加
  - `fix`: バグ修正
  - `docs`: ドキュメントの変更
  - `style`: コードのスタイル変更（機能に影響しない変更）
  - `refactor`: コードのリファクタリング（機能に影響しない変更）
  - `test`: テストの追加や修正
  - `chore`: その他の変更（ビルドプロセス、依存関係の更新など）
- `<subject>` は、変更の概要を簡潔に記述してください。

## プルリクエストのルール

- プルリクエストは、`dev` ブランチにマージされる前に、コードレビューを受ける必要があります。
- プルリクエストのタイトルは、コミットメッセージの `<subject>` と同様の形式で記述してください。
- プルリクエストの説明には、変更の目的や内容を詳しく記述してください。
- プルリクエストには、関連するチケット番号を含めてください。
- プルリクエストは、CI/CD パイプラインが成功するまでマージしないでください。
- プルリクエストがマージされた後は、関連するブランチを削除してください。
